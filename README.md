# Prüfwerk — HokuDeutsch

北海道大学のドイツ語授業・定期試験に向けた、静的HTML学習アプリです。ビルドやAPIキーは不要です。

## 収録内容

- Lektion 7〜12：過去・現在完了／zu不定詞とes／再帰と比較／受動／関係詞／接続法
- 各課に選択式・穴埋め・文変換・語順・和文独訳・独文和訳を各20問以上収録
- 後期文法問題780問以上（前期補修問題は別枠）
- トップページの「すきま時間に」から文法選択問題と語彙クイズへ直接移動
- 前期中間試験に対応した補修パック（活用・命令・冠詞と格・数詞・自己紹介）
- 教材掲載の不規則動詞80語
- 指定語彙16分野・350語句
- 語彙の4択「基本クイズ」（範囲、出題方向、問題数、苦手優先を設定可能）
- 30分の模擬試験2回分
- 正答率、失点タグ、復習キューの端末内保存

## GitHub Pagesで公開

1. このフォルダ内のファイルをGitHubリポジトリのルートへ置きます。
2. GitHubの `Settings` → `Pages` を開きます。
3. `Deploy from a branch` を選び、`main` / `root` を指定します。
4. 表示された公開URLを開きます。

サブフォルダで公開しても動くよう、すべて相対パスで記述しています。

## ローカル確認

`index.html` を直接開いても利用できます。オフラインキャッシュを含めて確認する場合は、任意の静的サーバーでこのフォルダを配信してください。

学習記録はブラウザの `localStorage` に保存され、外部には送信されません。
